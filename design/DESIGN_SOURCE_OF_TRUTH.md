# Design Source of Truth

The file `reference/quiet-focus-glass-approved.html` is the canonical approved Design Lab prototype for Verse Detector.

## Preservation contract

Future work must treat the following as locked unless the user explicitly requests a change:

- 468px maximum live-listener shell.
- Quiet Focus centered composition.
- 142px microphone orb and surrounding ring relationship.
- Product name + two circular header controls.
- Detected reference typography and placement.
- Peek-at-live-transcript affordance.
- Three preference pills.
- Four circular bottom tools + one long Start/Stop Listening button.
- Bottom-sheet/progressive-disclosure architecture.
- Cool blue/lilac/cyan glass palette.
- Gradient glow background fields.
- Colorful dark-mode microphone orb.

## Change rule

A future explicit request overrides only the exact part requested. Everything else remains protected.

Do not treat “make this workflow better” as permission to redesign adjacent locked UI.
